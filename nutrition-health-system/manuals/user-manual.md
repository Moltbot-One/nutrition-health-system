## 1. 快速开始

### 1.1 下载与安装

**iOS用户:**

1. 打开App Store
2. 搜索 "NutriHealth Pro" 或 "营养健康Pro"
3. 点击"获取"下载安装

**Android用户:**

1. 打开应用商店 (华为/小米/OPPO/vivo/应用宝)
2. 搜索 "NutriHealth Pro"
3. 点击"安装"下载安装

**微信小程序:**

1. 打开微信
2. 搜索小程序 "NutriHealth Pro"
3. 点击"立即使用"

### 1.2 注册与登录

**第一步: 选择注册方式**

- 手机号注册 (推荐)
- 邮箱注册
- 微信一键登录
- Apple ID登录 (iOS)

**第二步: 填写信息 (手机号注册)**

1. 输入手机号码
2. 点击"获取验证码"
3. 输入短信验证码
4. 设置登录密码 (8-20位, 包含字母和数字)
5. 勾选同意《用户协议》和《隐私政策》
6. 点击"注册"

**第三步: 完善资料 (可选)**

- 设置头像
- 填写昵称
- 选择性别
- 填写生日
- 设置身高体重

## 2. 账号管理

### 2.1 个人资料管理

**修改头像:**

1. 进入"我的"页面
2. 点击头像
3. 选择"更换头像"
4. 选择拍照或从相册选择
5. 调整裁剪区域
6. 点击"确认"

**修改基本信息:**

1. 进入"我的"页面
2. 点击"编辑资料"
3. 修改昵称、性别、生日、地区
4. 点击"保存"

### 2.2 健康档案管理

**身体数据录入:**

1. 进入"我的"-"健康档案"
2. 点击"身体数据"
3. 录入/修改:
   - 身高 (cm)
   - 体重 (kg)
   - 腰围 (cm)
   - 体脂率 (%)
4. 系统自动计算BMI

**健康史录入:**

1. 在健康档案中选择"健康史"
2. 录入:
   - 过敏史 (食物/药物)
   - 家族病史
   - 既往疾病
   - 手术史
   - 用药情况

### 2.3 账号安全

**修改密码:**

1. 进入"我的"-"设置"-"账号安全"
2. 选择"修改密码"
3. 输入原密码
4. 输入新密码 (8-20位)
5. 确认新密码
6. 点击"确认"

**绑定手机号:**

1. 进入"账号安全"
2. 选择"手机号"
3. 点击"更换手机号"
4. 验证原手机号
5. 输入新手机号
6. 获取验证码
7. 完成绑定

**登录设备管理:**

1. 进入"账号安全"
2. 选择"登录设备"
3. 查看已登录设备列表
4. 可远程退出其他设备

## 4. 膳食管理

### 4.1 记录饮食

**添加食物 - 方式1: 拍照识别**

1. 点击首页"记饮食"或"+"按钮
2. 选择"拍照识别"
3. 对准食物拍照
4. 等待AI识别
5. 确认或修正识别结果
6. 选择餐次 (早餐/午餐/晚餐/加餐)
7. 保存记录

**添加食物 - 方式2: 搜索添加**

1. 选择"搜索添加"
2. 输入食物名称 (如"米饭")
3. 从搜索结果选择
4. 输入分量 (克/碗/份)
5. 选择餐次
6. 保存

**添加食物 - 方式3: 扫码添加**

1. 扫描食品包装条形码
2. 自动获取食品信息
3. 确认并保存

### 4.2 查看营养分析

**今日概览:**

- 已摄入热量 / 目标热量
- 三大营养素占比 (饼图)
- 各营养素达标情况 (进度条)

**详细分析:**

- 早餐/午餐/晚餐/加餐 分别统计
- 热量、蛋白质、碳水、脂肪、纤维、维生素、矿物质
- 与推荐值对比

### 4.3 获取推荐

**智能推荐:**

1. 进入"膳食"-"推荐"
2. 系统根据:
   - 已摄入营养缺口
   - 您的饮食偏好
   - 健康目标
3. 推荐合适的食谱或食物

**今日食谱推荐:**

- 根据您的目标生成全天食谱
- 可一键应用到今日计划

## 5. 运动指导

### 5.1 运动能力评估

**开始评估:**

1. 进入"运动"页面
2. 首次使用点击"运动能力评估"
3. 回答评估问题:
   - 运动经历
   - 基础体能
   - 运动偏好
   - 可用时间
   - 场地设备
4. 获取评估结果和运动建议

### 5.2 查看运动计划

**今日运动:**

- 推荐运动类型
- 运动时长
- 预计消耗热量
- 动作视频教程

**运动计划:**

- 周计划预览
- 每日安排
- 强度变化曲线

### 5.3 记录运动

**自动记录:**

- 连接智能手环/手表
- 自动同步运动数据

**手动记录:**

1. 点击"记录运动"
2. 选择运动类型
3. 输入运动时长
4. 输入消耗热量 (可选)
5. 添加备注 (可选)
6. 保存

## 8. 常见问题

### Q1: 如何修改个人信息?

**A:** 进入"我的"-"编辑资料", 可修改头像、昵称、性别、生日等。

### Q2: 忘记密码怎么办?

**A:** 登录页点击"忘记密码", 通过手机号验证码重置密码。

### Q3: 如何连接智能手环?

**A:** "我的"-"设备管理"-"添加设备", 选择对应品牌按提示绑定。

### Q4: AI识别不准确怎么办?

**A:** 可点击"编辑"手动修正, 或重新拍摄更清晰的照片。

### Q5: 如何取消自动续费?

**A:** "我的"-"会员中心"-"管理自动续费"-"取消订阅"。

### Q6: 如何删除账号?

**A:** "我的"-"设置"-"账号安全"-"注销账号", 按提示操作。

### Q7: 客服联系方式?

**A:** 

- 在线客服: App内"我的"-"帮助与反馈"
